## Usage

```astro nocollapse
---
import { HamburgerMenu, HamburgerMenuBar, HamburgerMenuPanel, HamburgerMenuLink, HamburgerMenuGroup, HamburgerMenuSection } from '@bejamas/registry/ui/hamburger-menu';
---
<HamburgerMenu>
  <HamburgerMenuBar class="px-5" triggerClass="rounded-full bg-muted">
    <a href="/">Bejamas UI</a>
    <span slot="trigger-open" class="text-xs font-semibold">Menu</span>
    <span slot="trigger-close" class="text-xs font-semibold">Close</span>
  </HamburgerMenuBar>
  <HamburgerMenuPanel label="Main navigation" class="px-5">
    <p slot="header" class="mb-4 text-sm text-muted-foreground">Explore the site</p>
    <HamburgerMenuGroup label="Getting started" defaultOpen>
      <HamburgerMenuLink href="/introduction">Introduction</HamburgerMenuLink>
      <HamburgerMenuLink href="/installation">Installation</HamburgerMenuLink>
    </HamburgerMenuGroup>
    <HamburgerMenuSection label="Company">
      <HamburgerMenuLink href="/about">About us</HamburgerMenuLink>
    </HamburgerMenuSection>
  </HamburgerMenuPanel>
</HamburgerMenu>
```

## Props

| Prop | Type | Default |
|---|---|---|
| <code>class</code> | `string` | `""` |
| <code>closeOnOutsideClick</code> | `boolean` | `true` |
| <code>closeOnFocusOutside</code> | `boolean` | `false` |

`HamburgerMenuBar` accepts native `div` attributes, `class`, `triggerClass`, `defaultOpen`, `openLabel`, and `closeLabel`. `HamburgerMenuPanel` accepts native `nav` attributes, `label`, `class`, and `headerClass`, `itemsClass`, and `footerClass` for its internal regions.

## Examples

### Closed

```astro
<HamburgerMenu>
  <HamburgerMenuBar><a href="/">Bejamas UI</a></HamburgerMenuBar>
  <HamburgerMenuPanel>
    <HamburgerMenuLink href="/docs">Documentation</HamburgerMenuLink>
  </HamburgerMenuPanel>
</HamburgerMenu>
```

### Opened With Links

```astro
<HamburgerMenu closeOnOutsideClick={false}>
  <HamburgerMenuBar defaultOpen><a href="/">Bejamas UI</a></HamburgerMenuBar>
  <HamburgerMenuPanel>
    <HamburgerMenuLink href="/docs">Documentation</HamburgerMenuLink>
    <HamburgerMenuLink href="/components">Components</HamburgerMenuLink>
  </HamburgerMenuPanel>
</HamburgerMenu>
```

### Opened With Groups

```astro
<HamburgerMenu closeOnOutsideClick={false}>
  <HamburgerMenuBar defaultOpen><a href="/">Bejamas UI</a></HamburgerMenuBar>
  <HamburgerMenuPanel>
    <HamburgerMenuGroup label="Resources" defaultOpen>
      <HamburgerMenuLink href="/docs">Documentation</HamburgerMenuLink>
    </HamburgerMenuGroup>
  </HamburgerMenuPanel>
</HamburgerMenu>
```

## API Reference

Place `HamburgerMenuBar` and `HamburgerMenuPanel` directly inside `HamburgerMenu`, without slot attributes. The bar owns the trigger button and the panel owns the navigation landmark. Put `defaultOpen`, `openLabel`, `closeLabel`, and `triggerClass` on the bar; put the navigation `label` and panel styles on the panel. The panel accepts `header` and `footer` slots plus `headerClass`, `itemsClass`, and `footerClass`. The root manages Escape, outside clicks, and focus behavior. For a fixed-height preview, set `--hamburger-menu-panel-height` on a parent element.

The trigger supports mouse, touch, Enter, and Space. Escape closes an open panel, even after focus leaves it, and restores focus to the trigger when focus was inside the menu. Selecting a link closes the panel. Set `closeOnFocusOutside` to close the panel when keyboard focus leaves the menu; it defaults to `false`. Set `closeOnOutsideClick={false}` for previews that should stay open while navigating the page. Use `HamburgerMenuLink` for direct links, `HamburgerMenuGroup` for expandable sections, and `HamburgerMenuSection` for labelled sections that stay visible. The existing `MenuItem`, `MenuGroup`, and `MenuSection` names remain available. Groups use native disclosure elements and support keyboard interaction.
