## Usage

```astro nocollapse
---
import { HamburgerMenu, MenuItem, MenuGroup } from '@bejamas/registry/ui/hamburger-menu';
---
<HamburgerMenu variant="advanced">
  <a slot="brand" href="/">Bejamas UI</a>
  <MenuGroup label="Getting started" defaultOpen>
    <MenuItem href="/introduction">Introduction</MenuItem>
    <MenuItem href="/installation">Installation</MenuItem>
  </MenuGroup>
</HamburgerMenu>
```

## Props

| Prop | Type | Default |
|---|---|---|
| <code>class</code> | `string` | `""` |
| <code>variant</code> | `"simple" \| "advanced"` | `"simple"` |
| <code>defaultOpen</code> | `boolean` | `false` |
| <code>label</code> | `string` | `"Mobile navigation"` |

## API Reference

The 48px header remains visible while the panel fills the rest of the viewport. Add your own controls with the `brand`, `actions`, and `footer` slots. For a fixed-height preview, set `--hamburger-menu-panel-height` on a parent element.

The trigger supports mouse, touch, Enter, and Space. Escape closes the panel and restores focus to the trigger. Selecting a link closes the panel. Advanced groups use native disclosure elements and support keyboard interaction.
