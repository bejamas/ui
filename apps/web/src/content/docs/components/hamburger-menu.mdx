The trigger is a native button with `aria-expanded` and `aria-controls`. It opens with mouse, touch, Enter, or Space. Escape closes the panel and returns focus to the trigger. Links close the panel when selected. Groups use native disclosure elements, so they also work with the keyboard.

| Prop | Type | Default |
|---|---|---|
| `variant` | `"simple" \| "advanced"` | `"simple"` |
| `defaultOpen` | `boolean` | `false` |
| `label` | `string` | `"Mobile navigation"` |
