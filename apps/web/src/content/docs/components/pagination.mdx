## Rendering pages

Pagination is plain links and ships no JavaScript. Work out the pages on the server and map them to items:

```astro nocollapse
---
const current = Number(Astro.url.searchParams.get('page') ?? 1);
const total = 10;
const pages = [...new Set([1, current - 1, current, current + 1, total])]
  .filter((page) => page >= 1 && page <= total)
  .sort((a, b) => a - b);
---

<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href={`?page=${current - 1}`} disabled={current === 1} />
    </PaginationItem>
    {pages.map((page, index) => (
      <>
        {index > 0 && page - pages[index - 1] > 1 && (
          <PaginationItem><PaginationEllipsis /></PaginationItem>
        )}
        <PaginationItem>
          <PaginationLink href={`?page=${page}`} isActive={page === current}>{page}</PaginationLink>
        </PaginationItem>
      </>
    ))}
    <PaginationItem>
      <PaginationNext href={`?page=${current + 1}`} disabled={current === total} />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

## API Reference

### Parts

| Part | Element | Description |
|------|---------|-------------|
| `Pagination` | `<nav>` | Landmark with `aria-label="pagination"` |
| `PaginationContent` | `<ul>` | Row of items |
| `PaginationItem` | `<li>` | Wraps one link or the ellipsis |
| `PaginationLink` | `<a>` | A page link, styled as a `Button` |
| `PaginationPrevious`, `PaginationNext` | `<a>` | Adjacent page links with a chevron and a label |
| `PaginationFirst`, `PaginationLast` | `<a>` | First and last page links with a double chevron and a label |
| `PaginationEllipsis` | `<span>` | Marks a skipped range of pages |

### PaginationLink

`PaginationPrevious`, `PaginationNext`, `PaginationFirst` and `PaginationLast` take the same props.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `href` | `string` | | Page URL |
| `isActive` | `boolean` | `false` | Marks the current page with `aria-current="page"` |
| `disabled` | `boolean` | `false` | Drops the `href` and sets `aria-disabled="true"` |
| `size` | `"default" \| "sm" \| "lg" \| "icon" \| "icon-sm" \| "icon-lg"` | `"icon"` | Button size |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"` | `"outline"` when active, `"ghost"` otherwise | Button variant |

### PaginationPrevious, PaginationNext, PaginationFirst, PaginationLast

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | `"Previous"`, `"Next"`, `"First"`, `"Last"` | Visible label, hidden below the `sm` breakpoint. Pass `""` for an icon-only control |
| `aria-label` | `string` | `"Go to previous page"`, `"Go to next page"`, `"Go to first page"`, `"Go to last page"` | Accessible name |
| `size` | Button size | `"default"`, or `"icon"` when `text` is empty | Button size |

### Accessibility

- The root is a `<nav>` landmark labelled `pagination`.
- The current page link has `aria-current="page"`, so screen readers announce it as the current page.
- Previous, next, first and last links have an `aria-label` that names their destination.
- Disabled controls have no `href`, so they are skipped by the keyboard, and `aria-disabled="true"` for assistive technology.
- The ellipsis is hidden from assistive technology.

### Keyboard

Every page is a native link, so no script is needed.

| Key | Action |
|-----|--------|
| `Tab` / `Shift` + `Tab` | Move focus to the next / previous link |
| `Enter` | Follow the focused link |

### Data Attributes

| Attribute | Element | Description |
|-----------|---------|-------------|
| `data-active` | link | `"true"` on the current page, `"false"` otherwise |
| `aria-current` | link | `"page"` on the current page |
| `aria-disabled` | link | `"true"` when `disabled` |
