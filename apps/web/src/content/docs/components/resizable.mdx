## API Reference

### Panel Constraints

Sizes are percentages of the group. Set them on each `ResizablePanel`:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultSize` | `number` | even split | Initial size |
| `minSize` | `number` | `0` | Minimum size |
| `maxSize` | `number` | `100` | Maximum size |
| `collapsible` | `boolean` | `false` | Whether the panel can collapse below `minSize` |
| `collapsedSize` | `number` | `0` | Size when collapsed; must not exceed `minSize` |

### Events

The group emits custom events on its root element:

| Event | Detail | Description |
|-------|--------|-------------|
| `resizable:change` | `{ layout: number[] }` | Fired when the panel sizes change |

```js nocollapse
const group = document.getElementById('my-resizable');

group.addEventListener('resizable:change', (event) => {
  console.log('Layout:', event.detail.layout);
});
```

### Keyboard

| Key | Action |
|-----|--------|
| `ArrowLeft` / `ArrowRight` | Resize a horizontal group by `keyboardResizeBy` percent |
| `ArrowUp` / `ArrowDown` | Resize a vertical group by `keyboardResizeBy` percent |
| `Shift` + arrow | Move to the limit in that direction |
| `Home` / `End` | Minimize / maximize the preceding panel |
| `Enter` | Toggle the preceding panel when it is collapsible |
| `F6` / `Shift` + `F6` | Focus the next / previous handle in the group |

### Data Attributes

| Attribute | Element | Description |
|-----------|---------|-------------|
| `data-direction` | group, panel, handle | Layout axis (`horizontal` or `vertical`) |
| `data-state` | panel | `expanded` or `collapsed` |
| `data-collapsed`, `data-expanded` | panel | Present for the matching state |
| `data-active` | handle | `pointer` while dragging, `keyboard` while focused |
