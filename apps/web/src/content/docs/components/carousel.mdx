## Props

| Prop | Type | Default |
|---|---|---|
| <code>orientation</code> | `"horizontal" \| "vertical"` | `axis === "y" ? "vertical" : "horizontal"` |
| <code>variant</code> | `"single" \| "multiple"` | `"single"` |
| <code>defaultIndex</code> | `number` | `0` |
| <code>"data-loop"</code> | `boolean \| string` | `false` |
| <code>drag</code> | `boolean` | `true` |
| <code>controls</code> | `boolean` | `true` |
| <code>showCounter</code> | `boolean` | `orientation === "horizontal" && variant === "single"` |
| <code>counterLabel</code> | `string` | `variant === "multiple" ? "Page" : "Card"` |
| <code>previousLabel</code> | `string` | `"Previous slide"` |
| <code>nextLabel</code> | `string` | `"Next slide"` |
| <code>contentClass</code> | `string` |  |
| <code>axis</code> | `"x" \| "y"` | `"x"` |
| <code>snapType</code> | `"mandatory" \| "proximity"` | `"mandatory"` |
| <code>fade</code> | `boolean` | `false` |
| <code>class</code> | `string` |  |

## API Reference

### Events

The carousel emits custom events on its root element:

| Event | Detail | Description |
|-------|--------|-------------|
| `carousel:change` | `{ index: number }` | Fired when the active slide changes. The index is zero-based. |

```astro nocollapse
<Carousel id="my-carousel" aria-label="Featured cards" class="max-w-sm">
  <CarouselSlide><div class="rounded-lg bg-muted p-6">Card 1</div></CarouselSlide>
  <CarouselSlide><div class="rounded-lg bg-muted p-6">Card 2</div></CarouselSlide>
  <CarouselSlide><div class="rounded-lg bg-muted p-6">Card 3</div></CarouselSlide>
</Carousel>
```

```js nocollapse
const carousel = document.getElementById('my-carousel');

carousel.addEventListener('carousel:change', (event) => {
  console.log('Active slide:', event.detail.index);
});
```

### Programmatic Control

Dispatch `carousel:set` on the root to select a slide or navigate:

```js nocollapse
const carousel = document.getElementById('my-carousel');

// Select the third slide (zero-based index).
carousel.dispatchEvent(new CustomEvent('carousel:set', {
  detail: { index: 2 }
}));

// Move to the next slide.
carousel.dispatchEvent(new CustomEvent('carousel:set', {
  detail: { action: 'next' }
}));

// Move to the previous slide.
carousel.dispatchEvent(new CustomEvent('carousel:set', {
  detail: { action: 'prev' }
}));
```

### Data Attributes

The carousel exposes these attributes for styling and state queries:

| Attribute | Element | Description |
|-----------|---------|-------------|
| `data-orientation` | carousel | Current orientation (`horizontal` or `vertical`) |
| `data-variant` | carousel | Layout variant (`single` or `multiple`) |
| `data-loop` | carousel | Set to `"true"` to wrap navigation at either end; defaults to `"false"` |
| `data-index` | carousel | Zero-based index of the active slide |
| `data-dragging` | carousel | Present during an active drag gesture |
| `data-state` | carousel-item | Current slide state (`active` or `inactive`) |
